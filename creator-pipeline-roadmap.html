Motion swap roadmap

A motion swap pipeline the whole team can use from a browser link, on a GPU we rent by the hour, producing clips we'd post without explaining them. Open models we control, paid models as options.

Where we start

Node pack, batch runner, validator and setup scripts are built and tested. Wan Animate 2 rendered three clips on a rented A40: a stylised sample (22/25) and a photoreal streetwear woman driven by a street-dance clip (23/25), about 7.5 minutes per 81-frame clip at 480×848. The INSTARAW livestream showed stills tooling only; their video answer is "pay Seedance". We are ahead on motion swap.

Operating model

Rent a GPU by the hour (L40S recommended, ~$1/hr, ~4 min per clip), render in batches, and let the pod stop itself when idle. Serverless (pay per clip, nothing when idle) stays a later option; the same workflows run on both.

Quality: beyond 23/25

A clip you'd post without explaining it: 1080p, smooth, 5–10 seconds.

#DeliverableDetail
2.1Input guideReference photo rules (sharp, 2K, full body, plain background) and driving video rules (stable camera, even light, 24 fps, no blur). In the app as hints.
2.2Multi-seed + contact sheet3–4 seeds per job; auto contact sheet and face strip for picking in seconds.
2.3High tierFull Wan Animate 2 model + lightx2v LoRA, 720p render. About 2× render time.
2.4Finishing chainSeedVR2 video upscale ×2 → FILM interpolation 24→48 fps → Reality Finish. Second pass, toggle per job.
2.5Knob presets"Identity hold" (reference strength 1.2–1.3) and "Motion looseness" (pose end 0.7) as sliders.
2.6Chaining5–10 s clips by continuing motion across 81-frame chunks.

Backgrounds: A, B and C

Choose where the clip happens: described, the reference image's scene, or the original video's scene. Wan Animate 2 builds the background from text only, so each of these is a distinct route.

#DeliverableDetail
3AAuto background promptA vision model describes the reference image (or a video frame) into a background prompt. App option: preset / from reference / from video / custom. About a day.
3BReplace inside the original videoSCAIL-2 (open, all core ComfyUI nodes): SAM3 tracks the person → mask → character swapped in → colour match. Keeps the real background, lighting and camera. 2–3 days, ~22 GB models.
3CSeedance 2.5 Reference to VideoInstalled API node: reference image(s) + reference video + prompt, 1080p with generated audio. The route INSTARAW recommends; closed and per-clip, so it's our paid benchmark next to the open models. Shown as "Seedance (paid)". About a day.
3.4Three-way comparisonSame input pair through Wan Animate 2 and SCAIL-2 (open) and Seedance 2.5 (paid); scorecard and cost per clip; recommendation per use case.

Kling 3 Motion Control is deferred (13 Oct decision). The node is installed; adding it later is about a day.

Done when: any background mode or engine can be picked from the app; the comparison document exists.

Decisions made (13 October 2026)

  1. Default GPU: L40S.
  2. Paid engine: Seedance 2.5 only, ~$15–20 Comfy credits when Phase 3 starts. Kling deferred.
  3. Starter presets: six drafted; you rename and adjust.
  4. Tester for every phase: you.

Out of scope for now: public web app with logins, desktop installer, LoRA training for Wan Animate 2 (unproven), lip-sync, Kling 3 Motion Control (deferred).
